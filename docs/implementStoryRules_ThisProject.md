## README.md update checklist (AzureDoAutomatorPs)

Review each item and update `README.md` if the story introduced or changed it:
- [ ] New `.ps1` scripts → add to **Module Architecture** and **File Structure** sections
- [ ] New parameters on Upsert scripts → update the script's **Parameters** list
- [ ] Changed output shape of `Get*` scripts → update **Output Fields** / **Output enrichment**
- [ ] New config files or changed `appSettings.json` structure → update config sections
- [ ] MCP tool parameters changed → update **MCP Server Integration** tool categories
- [ ] Feature-level capability added → update the top-level **Features** bullet list
